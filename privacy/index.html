日本語

1. 基本方針

本アプリは、利用者が入力したすべての情報を利用者ご自身の端末内に保存します。提供者（開発者）は、利用者が入力したデータを収集・送信・保存・閲覧しません。提供者のサーバーは存在しません。

機種変更などに備える手段として、暗号化した控えを利用者ご自身の iCloud に自動保存する機能を用意していますが、この機能は初期状態ではオフです（第4項をご覧ください）。

2. 収集する情報

本アプリは、利用者に関する個人情報を一切収集しません。

  • 氏名・メールアドレス・アカウント登録はありません。
  • 利用状況の解析（アナリティクス）、広告、トラッキングは行いません。
  • 第三者の解析・広告用SDKは組み込んでいません。

3. 端末内に保存される情報

本アプリでは、利用者自身が以下のような情報を任意で入力・保存できます。

  • 予定・定期業務・タスク・メモ
  • 患者を識別するためのマーク（色・記号・番号・任意ラベル）
  • 入退院日、リハビリ算定に関する区分・起算日、患者ごとの自由メモ 等

本アプリは氏名を用いない管理を前提としています。ラベルや自由メモを含むすべての入力欄に、氏名・生年月日・介護保険情報など、個人の特定につながる情報を入力しないでください。 なお、算定日数の管理のため、疾患区分（脳血管疾患等・運動器 など）は選択式で保存されます。自由入力欄に具体的な疾患名や病状を書かないでください。これに反して入力したことにより生じる一切の結果（法令・所属先規程への抵触を含む）は、利用者の責任となります。入力する情報の適法性および関連規程・法令の順守は、利用者の責任です。

なお、第4項の「iCloud への自動保存」を利用者がオンにした場合に限り、これらの情報を含む暗号化された控えが、利用者ご自身の iCloud にも保存されます。

4. データの保存場所と iCloud

入力された情報は、利用者ご自身の端末内に保存されます。アプリ本体のデータ保存領域は、iOS の「iCloud バックアップ」（端末まるごとの自動バックアップ）の対象からは除外しています。

iCloud への自動保存（初期状態：オフ）

機種変更や再インストールでデータを失わないための手段として、暗号化した控えを、利用者ご自身の iCloud に自動保存する機能を用意しています。

  • ⚠️ この機能は初期状態でオフです。利用者が明示的にオンにした場合にのみ動作します。アプリ内の「設定 › iCloud バックアップ」からいつでも切り替えられます。
  • 保存先は利用者ご自身の iCloud アカウントであり、提供者のサーバーではありません。提供者はこの控えにアクセスできません。
  • 控えは端末上で暗号化されてから保存されます。復号に必要な鍵は利用者の iCloud キーチェーンにのみ保管されるため、提供者も、保存先を提供する Apple も、控えの中身を読み取ることはできません。
  • 控えに含まれる情報: 第3項に挙げた情報と同じ範囲です（予定・定期業務・タスク・メモ、患者を識別するマーク、入退院日、リハビリ算定に関する区分・起算日、患者ごとの自由メモ）。
  • 機種変更などで別の端末が作った控えを上書きする前に、その控えを1本だけ取り置きます（誤って上書きしてしまうのを防ぐためです）。したがって iCloud に置かれる控えは最大2本です。取り置いた控えは、アプリ内の「設定 › iCloud バックアップ」から確認・復元できます。
  • iCloud の利用そのものは Apple のサービスであり、Apple の利用規約およびプライバシーポリシーが適用されます。

手動での書き出し

アプリ内の「設定 › データ › バックアップを書き出す」で、ファイルとして保存することもできます。書き出したファイルの保存先・管理は利用者の責任となります。⚠️ 自動保存がオフのあいだ、控えは自動では取られません。端末を換えたり、アプリを入れ直したりすると、入力した内容はすべて消えます。

5. 第三者提供

提供者は利用者のデータにアクセスできないため、第三者への提供・共有は行いません。

6. データの削除

端末内のデータは、アプリ内で各項目を削除するか、アプリを削除することで消去できます。iCloud に保存された控えは、アプリ内の「設定 › iCloud バックアップ › iCloud の控えを削除」から削除できます（取り置いた控えも含めて、すべて削除されます）。提供者側に保存されるデータはありません。

7. 医療・算定に関する注意

本アプリは、疾病の診断・治療・予防に使用されることを目的としていません。医療機器ではありません。本アプリはリハビリ専門職の業務予定・タスクの管理を目的としており、診断や治療の判断には使用しないでください。リハビリ算定日数などの表示はあくまで目安であり、正式な算定可否は各施設・保険の基準でご確認ください。

English (summary)

This app stores the information entered by the user on the user's own device. The developer does not collect, transmit, store, or access any of it. There is no developer-operated server. There are no accounts, no analytics, no advertising, and no third-party tracking SDKs.

Users may optionally enter schedule, task, and patient-management data (patients are identified by color/symbol/number/label, not by name), including admission/discharge dates, a rehabilitation billing category and its start date, and a free-text note per patient. Users must not enter information that could identify an individual (such as names, dates of birth, or long-term-care insurance details) in any field, including labels and notes. Note that a rehabilitation billing category is stored as a selectable option because it is required to track billing-day limits; users should not write specific diagnoses or clinical details into free-text fields. Any consequences arising from doing so are the user's responsibility, and users are responsible for complying with their own organization's rules and applicable laws.

The app's data store is excluded from the iOS "iCloud Backup" (whole-device backup). Separately, the app offers an option to automatically save an encrypted copy to the user's own iCloud so that data is not lost when changing devices. This option is OFF by default and only operates if the user explicitly turns it on (Settings › iCloud Backup). The copy is stored in the user's own iCloud account, not on any developer server; it is encrypted on the device before being saved, and the decryption key is kept only in the user's iCloud Keychain, so neither the developer nor Apple can read its contents. The copy contains the same range of information listed above. Before overwriting a copy created by a different device, the app preserves that copy once (to prevent accidental loss), so at most two copies may be stored in iCloud. A preserved copy can be reviewed and restored from within the app (Settings › iCloud Backup). Use of iCloud itself is an Apple service governed by Apple's terms and privacy policy.

Users can also export a backup file manually (Settings › Data › Export backup); managing that file is the user's responsibility. ⚠️ While automatic saving is off, no copy is created automatically, and all entered data is lost if the device is replaced or the app is reinstalled.

Because the developer has no access to user data, no data is shared with third parties. Deleting items in the app or deleting the app removes the data on the device. The copies stored in iCloud can be deleted from within the app (Settings › iCloud Backup › Delete iCloud copy); this removes any preserved copy as well. There is no server-side copy.

This app is not intended for use in the diagnosis, treatment, or prevention of disease. It is not a medical device. It is intended to help rehabilitation professionals manage their work schedules and tasks, and must not be used for diagnostic or treatment decisions. Any rehabilitation-billing-day figures shown are estimates only.
